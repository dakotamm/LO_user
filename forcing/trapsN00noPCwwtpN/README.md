# LO/forcing/traps###

traps### (e.g. trapsN00 as of 2025.08.26) is the version of TRAPS forcing that most accurately represents realistic conditions.

For general notes on the forcing scripts, please see user notes in the traps_notes directory [here](https://github.com/parkermac/LO/tree/main/traps_notes/forcing_notes).

DM: copy of LO/forcing/trapsN00 with NO3 and NH4 set to zero for the two Penn Cove WWTPs (COUPEVILLE STP, PENN COVE WWTP; both was24), following the West Point change in LO/forcing/trapsN00noWP. Their flow, temperature, salinity, DO, TIC and TAlk are unchanged, as are all other WWTPs and rivers. Used by wb1_n0_xn11abbur00.
